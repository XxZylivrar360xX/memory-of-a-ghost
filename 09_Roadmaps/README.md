# 09_Roadmaps

Carpeta exclusiva para checklists/roadmaps de eventos y arcos **confirmados con el autor pero todavía no redactados en prosa**.

## Qué va aquí

Documentos `Plan_*.md` (o `Roadmap_*.md`) que fijan, antes de escribir cualquier escena:
- el cimiento de un evento o arco (anclajes, fricciones ya resueltas, decisiones de canon),
- la lista de escenas/movimientos que lo componen, en orden,
- el checklist de beats obligatorios de cada una.

Nacen casi siempre del triage de una nota de incubadora de Codex (`99_Reference/Agent_Notes/codex/`), afinados en conversación con el autor. Metodología fijada el 2026-07-18: ante una incubadora densa, primero el checklist de beats por escena, después la prosa — nunca al revés.

## Qué NO va aquí

- Ideas crudas sin triage todavía (eso sigue siendo `07_Unsorted_Ideas/`).
- Prosa ya escrita (eso vive en `05_Dialogues/`, `10_Chapters/`, etc.).
- Notas de incubadora de Codex sin resolver (eso vive en `99_Reference/Agent_Notes/codex/`).

## Ciclo de vida de un documento aquí

1. Se crea al triar una incubadora densa (o al planear un arco grande sin incubadora previa).
2. Se actualiza escena por escena a medida que cada movimiento se redacta (marcar hecho, no borrar el checklist).
3. Cuando todo el arco está escrito, el documento queda como registro histórico de cómo se decidió — no se elimina.
