# Mapa cronologico v0.1 de `05_Dialogues`

**Hallazgo:** `05_Dialogues/` ya tiene mucha cronologia implicita, pero esta repartida entre nombres de archivo, `INDEX.md`, `01_Timeline/` y planes recientes. No existe todavia una vista unica que permita leer las escenas en orden narrativo.

**Por que:** para escribir los libros reales despues, el orden por carpeta emocional no basta. Funciona para autoria de escenas, pero no para convertirlas en capitulos.

**Sugerencia:** usar este mapa como primera capa operativa. No lo trataria como canon cerrado: conviene convertirlo mas adelante en un documento real de `07_Unsorted_Ideas/` o `99_Reference/` si Victor decide que ya vale como herramienta editorial permanente.

**Severidad:** baja

**Canon bloqueado?:** no

## Criterio de lectura

- **Orden fuerte:** escena ubicada por `INDEX.md`, `01_Timeline/`, nombre de evento o secuencia numerada.
- **Orden inferido:** escena ubicada por etiqueta de archivo (`TakenKing`, `Risen`, `PostFinalShape`, etc.) pero sin suborden fino validado escena por escena.
- **Pendiente de lectura fina:** escena cuyo lugar macro es claro, pero cuyo lugar exacto entre otras escenas del mismo bloque requiere releer texto.
